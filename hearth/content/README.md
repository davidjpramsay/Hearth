# Bring your own game data

Hearth includes original game code and tiny original demo/test puzzles. It does not distribute
NYT puzzles, NYT answer lists or downloaded word databases. Hearth's MIT licence does not cover
third-party content.

- **[Connections](connections/README.md):** obtain word-group puzzles you have permission to use.
- **[Word Guess](word-guess/README.md):** obtain a permitted five-letter answer list and guess dictionary.
- **Connect Four:** no database, account or external service needed.

Ask your agent to help acquire permitted data, keep required notices, validate the format and install
it privately. Keep data outside Git, browser public folders, source ZIPs and container images.
Hearth does not download content from other game sites during play.
